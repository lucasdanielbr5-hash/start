START diversão com propósito
Sobre a START

A gente cuida da diversão para você curtir o momento.

Uma festa acontece em poucas horas, mas as lembranças ficam por muito tempo. É por isso que a START não entra apenas para “ocupar” as crianças.

Nosso trabalho é criar momentos de interação, movimento e criatividade para que cada criança tenha espaço para brincar, participar e se sentir parte da festa.
